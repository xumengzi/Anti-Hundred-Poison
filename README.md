## 屏蔽范围

1. 搜索引擎首页与搜索无关的按钮 / 广告 / 热搜等元素，重点净化百度
2. 百度全家桶（百度知道、百度文库、百度百科等系列站点）
3. 搜索页顶部、右侧的推广位与设置项
4. 着重屏蔽 **CSDN**（如有冒犯，请勿使用）

> 仅推荐专业人士使用，不承担任何后果

## 安装方法

1. 下载(克隆), 把文件夹保存起来(这个就是解压后的谷歌插件)
2. 打开谷歌浏览器,进入插件设置界面`chrome://extensions/`
3. 打开「开发者模式」-「加载已解压的扩展程序」，右下角有一个刷新按钮，那是为了更新的，如果是更新那么点击刷新
4. ![安装方法](./imgs/2.png)
5. 愉快的搜索吧

## 如何更新

1. 如果原先是克隆的，那么执行`git pull`，记得去浏览器插件管理去刷新一下，加载最新的资源，看不懂这个就执行步骤 2
2. 其他：再下载一次也行，执行一遍**安装方法**即可

## 屏蔽原理

1. 如果是用百度搜索，且条件有关于百度全家桶相关的字眼，那么这条搜索结果将会被删除;
2. 会隐藏搜索界面右侧，顶部，无关搜索的结果

## 隐私说明

Ad Terminator 在本地读取搜索页面内容以匹配净化规则，不收集或上传搜索词、浏览记录及页面正文。站点开关和后续的自定义规则保存在 `chrome.storage.sync` 中，可能通过用户登录的 Chrome 账号跨设备同步；本页拦截计数仅在扩展内部临时处理。项目主页与反馈链接仅在用户主动点击后访问 GitHub。

权限用途：`storage` 用于保存设置，`activeTab` 用于 Popup 查询和操作当前页面，`webNavigation` 用于页面导航时清理旧计数。

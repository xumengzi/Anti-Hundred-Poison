FAQ

常见问题

它会修改搜索引擎的数据吗？

不会。扩展只在你的浏览器中隐藏或恢复页面元素，不会修改搜索引擎服务器上的任何数据。

为什么暂时不能从 Chrome 商店安装？

商店版本仍在准备中。目前可以从 GitHub 下载源码，通过 Chrome 开发者模式加载。

四个搜索引擎的能力完全一样吗？

百度和 Bing 支持页面净化与动态结果过滤；360 搜索和搜狗搜索目前提供基础页面净化。

遇到误拦截怎么办？

可以在 Popup 中临时显示本页结果，或前往 GitHub Issues 提交误拦截反馈。
